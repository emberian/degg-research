# Experiments

No experiment implementation has landed.

Each future experiment receives:

- a stable identifier;
- a relation version;
- a backend version;
- a frozen parameter manifest;
- synthetic/public input provenance;
- expected exact outputs;
- hardware/software environment;
- execution command;
- raw results;
- canonical summary;
- failure and leakage report;
- SHA-256 digests.

Private orders, keys, credentials, unpublished user data, and production chain
state do not belong here.
