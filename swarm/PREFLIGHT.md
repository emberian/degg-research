# Research Agent Preflight

Before beginning:

1. Read AGENTS.md completely.
2. Read docs/VERDICTS.md and paper/CLAIM_LEDGER.md.
3. State the exact owned paths.
4. Inspect git status and preserve existing work.
5. Declare whether the task is literature, formalization, implementation,
   benchmark, regulation, or review.
6. Declare allowed external access and cost. Default is no paid service, no keys,
   no chain action, and no regulator contact.
7. List the strongest claim the work could honestly support.
8. List the evidence required to support it.
9. List privacy, provenance, patent, and licensing boundaries.
10. Name the stop condition.

## Required handoff

- paths changed;
- claim-status changes;
- exact commands run;
- tests/measurements and failures;
- artifact digests;
- assumptions and nonclaims;
- security/privacy model;
- unresolved joins;
- whether any external state changed.

Never report a design as implemented, an implementation as measured, a
measurement as secure, or a security argument as deployed.
